OpenWeatherMap API Key

Connect live telemetry data to your dashboard

To fetch real-time worldwide weather and 5-day forecasts, enter your free OpenWeatherMap API key below. The key is securely stored in your local browser session (or configure in config.js).

How to get a FREE API Key:
  1. Visit home.openweathermap.org/users/sign_up.
  2. Create an account and confirm your email.
  3. Go to the API Keys tab in your profile.
  4. Copy your key and paste it above.
Notice: Newly generated OpenWeatherMap keys typically require 10 to 30 minutes to activate on OpenWeatherMap servers.
