# Dynamic Task Manager & Productivity Tracker

A simple and user-friendly task management application developed as part of the **Datheon Full Stack Web Development Internship — Task 2**.

## 📌 About the Project

The Dynamic Task Manager helps users organize their daily activities, manage tasks, and track their productivity through a clean and simple interface.

## ✨ Features

- ➕ Add new tasks
- 📝 View and manage tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🎨 Simple and user-friendly interface
- 📱 Responsive design (if supported by the current implementation)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `Index.html` in your web browser.
4. Start adding and managing your tasks.
